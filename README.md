# AVPlayer stalls at the end after deselecting an ended subtitle and seeking

1. AVPlayer streams 3 HLS tracks: subtitles, audio, video.
2. The subtitle track arrives quickly (it is one WebVTT segment).
3. Subtitle track reaches end of stream ✅
4. Subtitles are turned off: `item.select(nil, in: legibleGroup)`.
5. Seek. The subtitle's end of stream is cleared ❌, but the off track never reports it again.
6. Audio and video reach end of stream ✅ ✅
7. AVPlayer keeps waiting for the subtitle track: `PlaybackStalled`, never `DidPlayToEndTime`.

## Run

No network needed: the HLS is generated by `gen.sh` and served from 127.0.0.1 inside the app.

```
xcodebuild -project AppleHLSEOSStallRepro.xcodeproj -scheme AppleHLSEOSStallRepro -configuration Release -destination 'platform=macOS' -derivedDataPath build CODE_SIGN_IDENTITY=- build
build/Build/Products/Release/AppleHLSEOSStallRepro.app/Contents/MacOS/AppleHLSEOSStallRepro -mode bug    # RESULT bug stalled
build/Build/Products/Release/AppleHLSEOSStallRepro.app/Contents/MacOS/AppleHLSEOSStallRepro -mode subon  # RESULT subon ended (skips step 4)
```

Same on iOS: build for `generic/platform=iOS` with your team, launch with `-mode bug`.

Reproduced on macOS 26.7.2 and iPadOS 26.5.
